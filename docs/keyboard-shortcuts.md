# Keyboard Shortcuts

Press **Ctrl+/** at any time to open the shortcuts help dialog in the app.

## Global

| Shortcut | Action |
|----------|--------|
| Ctrl+K | Open command palette |
| Ctrl+/ | Show keyboard shortcuts dialog |
| Ctrl+Shift+L | Toggle light / dark theme |
| Esc | Close dialog or drawer |

## Navigation

| Shortcut | Action |
|----------|--------|
| Ctrl+B | Toggle sidebar collapse |
| Ctrl+, | Open settings |
| Ctrl+1–9 | Jump to sidebar tab by index |
| Alt+Left | Navigate back |
| Alt+Right | Navigate forward |

## Tables

| Shortcut | Action |
|----------|--------|
| Ctrl+A | Select all rows |
| Shift+Click | Range-select rows |
| Delete | Remove selected rows |
| Ctrl+F | Focus search / filter field |
| Enter | Open selected row detail |

## Forms

| Shortcut | Action |
|----------|--------|
| Ctrl+Enter | Submit form |
| Ctrl+Z | Undo last change |
| Tab | Move to next field |
| Shift+Tab | Move to previous field |

## Queue (Admin)

| Shortcut | Action |
|----------|--------|
| Space | Call next patient |
| Ctrl+N | New walk-in |
